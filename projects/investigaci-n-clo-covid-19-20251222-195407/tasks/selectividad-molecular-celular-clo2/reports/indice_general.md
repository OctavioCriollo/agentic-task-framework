## HALLAZGOS CLAVE INTEGRADOS

### Respuesta central

**¿Puede ClO₂ ser selectivo hacia virus vs células?**

```
NIVEL MOLECULAR (química directa):
✗ NO

NIVEL SISTÉMICO (biología indirecta):
○ POSIBLE pero DÉBIL (factor 5-30×)

CONCLUSIÓN:
Selectividad es INSUFICIENTE para uso terapéutico seguro.
```

### Datos críticos

**Índice de Selectividad (SI):**
```
ClO₂ (estimado): 5-30
Mínimo requerido: >100
Antivirales aprobados: >100-1000

VEREDICTO: INSUFICIENTE
```

**Ratio de abundancia:**
```
Tioles humanos : Tioles virales = 89:1

ClO₂ oxida preferentemente proteínas HUMANAS (estadística)
```

**Secuestro por GSH:**
```
>99% de ClO₂ reacciona con GSH
<1% alcanza proteínas (virales + humanas)

Protección celular, pero también protección viral
```

### Mecanismos de selectividad evaluados

| Escenario | Factor | Evaluación |
|-----------|--------|------------|
| A. Espacial (extracelular) | 1.5-2× | Insuficiente |
| B. GSH bajo (células infectadas) | 2-3× | Complementario |
| C. HOCl vía MPO (neutrófilos) | 10-100× | Plausible si fagocitosis |
| D. Daño diferencial (reparación) | 5-50× | Contradice virus intracelular |
| E. Inmune indirecta (marcaje) | Variable | Incierto |

**TOTAL COMBINADO:** 5-30× (insuficiente)

### Validaciones ausentes

```
✗ SI experimental (ClO₂ vs SARS-CoV-2 en células): NO MEDIDO
✗ Farmacocinética en humanos: DATOS ESCASOS
✗ Estudios preclínicos (animal): NO REALIZADOS
✗ Ensayos clínicos controlados: NO EXISTEN
```

### Recomendación científica

```
❌ NO usar ClO₂ sistémico para COVID-19

Razones:
1. Falta evidencia de eficacia
2. Selectividad insuficiente (SI marginal)
3. Riesgo de toxicidad (metHb, hemólisis)
4. Existen alternativas probadas (Paxlovid, Remdesivir)

✓ Investigación rigurosa justificada:
 - In vitro (medir SI experimental)
 - Si positivo → Preclínicos
 - Si preclínicos positivos → Clínicos
```

## DATOS TÉCNICOS DE REFERENCIA RÁPIDA

### Constantes de velocidad (k)

| Target | k (M⁻¹s⁻¹) | Reactividad |
|--------|------------|-------------|
| Tiol libre (Cys-SH) | 10⁶-10⁷ | Muy Alta |
| GSH | 10⁶ | Muy Alta |
| Triptófano (Trp) | 10⁴-10⁵ | Alta |
| Puente disulfuro (S-S) | 10³-10⁴ | Baja |

### Composición de proteínas

**Spike SARS-CoV-2:**
- 1273 aa, 40 Cys (3.14%), 7 Trp (0.55%), 28 Tyr (2.20%)
- Total oxidable: 7.23%

**Proteoma humano promedio:**
- Cys: 1.38%, Trp: 1.08%, Tyr: 2.93%
- Total oxidable: ~7.71%

**Diferencia:** Spike tiene ~2× más Cys, pero comparable en total oxidable.

### Concentraciones celulares

| Componente | Concentración |
|------------|---------------|
| GSH (célula sana) | 5 mM |
| GSH (célula infectada) | 1.5-2 mM |
| Tioles proteicos libres | ~0.1 mM |
| ClO₂ (dosis típica, estimado) | 10-100 μM |

### Índice de Selectividad (comparativo)

| Agente | SI | Uso |
|--------|----|-----|
| Paxlovid | >1000 | Antiviral (aprobado) |
| Remdesivir | >100 | Antiviral (aprobado) |
| Artemisinina | >1000 | Antimalárico (aprobado) |
| Bleomicina | 2-5 | Cáncer (tóxico, aceptable) |
| **ClO₂** | **5-30** | **NO aprobado (insuficiente)** |

## RESUMEN FINAL EN UNA PÁGINA

### La pregunta

**¿Puede ClO₂ discriminar entre virus (SARS-CoV-2) y células humanas, permitiendo efecto antiviral sin toxicidad?**

### La respuesta

**NO a nivel molecular. POSIBLE PERO DÉBIL a nivel sistémico.**

### Por qué NO (química)

1. ClO₂ oxida Cys/Trp/Tyr indiscriminadamente (viral = humano)
2. Proteínas humanas >> virales (ratio 89:1)
3. GSH secuestra >99% de ClO₂
4. No hay diferencia termodinámica (ΔG viral ≈ ΔG humano)

### Por qué DÉBIL (biología)

Mecanismos indirectos:
- Espacial (virus libre): Factor 1.5-2×
- GSH bajo (infectadas): Factor 2-3×
- HOCl (fagocitosis): Factor 10-100× (limitado)
- Inmune: Variable (incierto)

**TOTAL:** Factor 5-30× (vs >100× requerido)

### Comparación

| | ClO₂ | Paxlovid |
|-|------|----------|
| SI | 5-30 | >1000 |
| Mecanismo | Oxidación inespecífica | Inhibidor específico |
| Selectividad | Marginal | Muy Alta |
| Evidencia | Escasa | Sólida |
| Aprobación | NO | SÍ |

### Conclusión científica

```
Selectividad de ClO₂ es INSUFICIENTE para uso terapéutico seguro.

Evidencia experimental rigurosa (in vitro → preclínica → clínica)
es OBLIGATORIA antes de considerar uso clínico.

Estado actual: EVIDENCIA INSUFICIENTE.

Recomendación: NO usar ClO₂ para COVID-19 fuera de investigación controlada.
```
