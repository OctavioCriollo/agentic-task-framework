# Analisis de Simbolos en Framework

## Layer 1 Contexto Conversacional

El usuario esta construyendo una metodologia profesional de documentacion Markdown para el framework Agentic Task v2.2.

Contexto del proyecto El framework tiene multiples documentos md Se han aplicado estandares de simbolos v3.2 recientemente El usuario busca establecer estandares claros basados en evidencia Principio rector Usa formato para mejorar claridad no para decorar.

---

## Layer 2 Tarea Tecnica

Objetivo Auditar completamente el uso de simbolos en la documentacion del framework.

Metodologia

1. Inventariar documentos Markdown Encuentra todos los archivos md en el framework Categoriza por tipo CLAUDE.md README.md docs reports etc

2. Analizar simbolos presentes Extrae todos los simbolos Unicode usados Clasifica en funcionales vs decorativos Cuenta frecuencia de uso Calcula densidad simbolos por 100 palabras

3. Evaluar uso en contextos Simbolos en titulos headers Simbolos en tablas Simbolos en listas Simbolos en parrafos

4. Identificar inconsistencias Documentos que usan simbolos diferentes para mismo proposito Violaciones del estandar v3.2 Densidad excesiva mayor 7 por 100 palabras

Output esperado

Crea reporte analisis_simbolos_actuales.md con

1. Inventario de Documentos tabla
2. Simbolos Detectados clasificados funcional decorativo
3. Analisis de Densidad por documento
4. Uso por Contexto headers tablas listas parrafos
5. Inconsistencias Encontradas lista detallada
6. Evaluacion segun Estandar v3.2 compliance score
7. Recomendaciones que cambiar
